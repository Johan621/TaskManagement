# Task Management System

MERN stack task management mini-project for the Smart Interviews SDE assignment.

## Stack
- Frontend: React (Vite)
- Backend: Node.js + Express
- Database: MongoDB
- Authentication: JWT

## Repository structure

```text
backend/
frontend/
```

## Backend setup

```bash
cd backend
npm install
npm run dev
```

Create `backend/.env` from `.env.example` and provide your MongoDB connection string and JWT secret.
